# Contributing to the pilot

Create a branch or fork from `main` for your team's work. Keep an untouched
baseline and record the commit used for each experiment. Coordinate ownership
of interfaces across the four teams before changing their contracts.

Each contribution should explain the problem, evidence, resulting behavior,
tests, limitations and integration steps. Link individual investigation and
peer review records. AI use is optional; document material assistance and
independent validation when used.

Run `python -m unittest discover -s tests -v`. Include tests or measurements that
distinguish the original behavior from the correction while preserving legitimate
operation. Simulator success does not validate a hardware adapter.

Submit to the instructor-designated team repository or channel. The instructors
will announce when findings may be published during the exercise. Agree on a
merge order and run the combined system after integrating each contribution.
Do not commit credentials, personal data or private interview transcripts.
