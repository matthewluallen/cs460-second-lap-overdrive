# Relative lane controls after Guardian's forward acceptance

Guardian completed the accepted SDK scan and three forward-only laps on `84f799c`. Before proceeding to the operator-requested left/right tests, review found that the ordinary browser/keyboard nudge helper used `driver.input.lane ?? car.targetLateral`. Forward-only driving updates the measured lateral position without issuing a steering target, so the retained target can remain zero. With a measured position of +22.5 mm and no lane intent, the old first left press targets +22.5 (no shift); the first right targets −22.5 (45 mm across). This is a host target-selection defect, not evidence of a firmware protocol difference or the cause of Groundshock's independent spinning.

The repaired physical discrete-control path uses a fresh ordinary printed-code lateral reference from the current drive. Its first left/right target is measured lateral plus/minus 22.5 mm, without rounding that measured value onto an unrelated lane grid. Successive explicit nudge targets may accumulate within the same drive. A missing, stale or previous-drive optical reference refuses a new press instead of storing an intent that might move unexpectedly later. Simulator/legacy behavior is preserved. The Car transport still rechecks its reference immediately before dispatch.

The bounded diagnostic previously exposed only a left test. It now accepts direction +1 or −1, with separate left/right buttons, direction-specific countdown/HUD and trace annotation. Both use the same policy: a three-second countdown, requested speed at most 300 mm/s, four-second overall window, one request only after a fresh ordinary-straight code with positive speed, at least 250 mm of straight remaining and 750 ms of test time remaining. The target stays within the existing lane bounds; STOP follows within 750 ms of the request. Firmware cancellation still opens the shared pit and stops forward driving. No firmware byte layout, SDK preamble, timeout, arming or cancellation policy is changed.

For the physical comparison, place Guardian near the entrance of the long ordinary straight, on a printed lane with room in the test direction. The start/finish sections do not satisfy this diagnostic's ordinary-straight gate. Starting at the end of the lap could expire the short window before the opposite straight is reached. This repair covers discrete browser/keyboard intent and the bounded diagnostic. Phone tilt and gamepad steering use absolute targets.
