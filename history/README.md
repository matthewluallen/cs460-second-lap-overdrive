# Scenario Git history

This branch contains the fictional development history, from February 3, 2025
through the September 15, 2026 pilot snapshot. Dates, identities and business
records are educational fiction, as disclosed in `SIMULATION_NOTICE.txt`.

Inspect the native history from your checkout:

```sh
git log --format=fuller
git show <commit>
git diff <older> <newer>
```

Compare a claim with the code and records available at the relevant revision.
The current student brief supersedes earlier assignment wording. Commit dates
alone do not prove when work occurred, who performed it, or who owns its rights.
